# User Guide

## Quick Start Guide

1. **Load Extension (30 seconds)**
   - Open Chrome Extensions: `chrome://extensions/`
   - Enable Developer Mode.
   - Click **Load unpacked** and select the `EXT` folder.

2. **First Use (1 minute)**
   - Open a test document (`test_data.txt` or a Google Doc).
   - Click the extension icon in the toolbar.
   - Enter the target date (e.g., `Nov 6`).
   - Click **Analyze Doc** and view results with highlighted keywords.

## Usage

1. Open a Google Doc with your SEO submissions.
2. Click the extension icon.
3. Enter the target date found in your document header.
4. Click **Analyze Doc**.
5. View results:
   - Green highlights = exact matches.
   - Red highlights = gapped matches.
   - Summary statistics and keyword tables are displayed.

## Troubleshooting

- **Extension won't load**: Verify all files are present and `manifest.json` has no errors.
- **"No text found"**: Ensure you're on a Google Docs tab, refresh the page, or select text manually.
- **No results shown**: Check the date matches exactly and the document format follows the required structure.

## Success Indicators

- ✅ Extension loads without errors.
- ✅ Popup opens when clicked.
- ✅ Date input accepts text.
- ✅ Analyze button responds.
- ✅ Results show with highlights.
